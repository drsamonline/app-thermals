# Thermals — user guide

**Version 1.8.1 · PolyForm Noncommercial 1.0.0**

Look up a remedy and read what every bundled source says about its thermal reaction — each statement
quoted verbatim against the source that wrote it. Above the quotes sits a summary **computed from
those quotes**.

## The four summaries, and the one that matters

| Summary | When |
|---|---|
| `sources agree (n)` | two or more bundled sources speak, and all point the same way |
| `sources disagree` | two or more speak and they point opposite ways |
| **`one source only`** | exactly one bundled source speaks — **the common case, and never agreement** |
| `unclassified` | no bundled source carries a thermal statement for that remedy: no quote, no summary |

The third row is the point of the app. A single source is one author's opinion, not a consensus, and
the summary says so instead of letting a lone sentence look like a finding.

## Dated notes

A **dated note** is a temporary shift — an acute fever, a pregnancy, a proving — with an end date.
When the date passes the note stays visible, marked expired, and the constitutional quotes are
untouched. Nothing is deleted by time passing; it is only marked.

## What it must not do, and does not

- It never assigns, derives, averages or infers a thermal state. One row is one remedy, one source,
  one verbatim sentence.
- It never derives a classification from rubric counts or grades.
- It never selects or prescribes a remedy, and it does not decide anyone's thermal state.
- `ambithermal` is not a state this app looks for: no bundled source uses the word.
- A remedy no source speaks about is `unclassified` — no quote, no summary.

## Why the row count can be trusted

The extraction rule ships with the data, because the row count is a property of it. A **thermal
statement** is a sentence in a source's own words containing one of the listed phrases as whole
words, case-insensitively. Change the rule and the count changes; that is the honest relationship
between the two.
