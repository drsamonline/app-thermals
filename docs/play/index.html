The rule this app ships

  • One row is one remedy, one source, one verbatim sentence. The app quotes; it never labels.
  • The summary is computed from the sentences: sources agree (n), sources disagree, or one source only. One source is never agreement.
  • A remedy no source speaks about is unclassified — it carries no quote and no summary.
  • A dated note is a temporary shift with an end date. It never rewrites the constitutional statement.
